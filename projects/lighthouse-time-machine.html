The Jam

Lighthouse Time Machine was made for the 2026 Wolf Jam with the theme of “Visibility”. It is a 2D top down management game where you must use the light from your lighthouse to peer through the fog, and guide ships safely to port. I led a design team of 5 to create this project within the 24 hour time limit of the game jam.

The Pivot

Original Concept

  • A 2D side-on view of a lighthouse with an emphasis on atmosphere.
  • The player would run around the lighthouse to activate different lamps to defend against demons coming from all sides.

Problem

  • While developing our initial concept, we were stuck. The core gameplay loop simply wasn’t fun or rewarding enough, and we realized it would become repetitive and mundane.
  • We tried to brainstorm ways to improve the concept, but none of the ideas would be realistically achievable in the limited time of the game jam.

Decision

We as a team decided to completely pivot our game idea 5 hours in. Our new idea was the simpler, more arcadey style game we have now.

Result

This pivot was a scary decision but made intentionally, and it paid off. We were able to deliver a well polished and fun game with a satisfying and rewarding core loop. We ended up placing 2nd in the jam, proving our pivot was the right decision.

Dynamic Music

Lighthouse Time Machine features music that speeds up as the game goes on. I wrote the music and implemented this system.

How it works

  • The music switches between 2 different loops, the slow loop and the fast loop.
  • The game starts in the menu with the slow loop, and when the loop ends it checks to see if the game is running.
  • If the game is running it will play the transition that speeds up over time and then continue looping the fast loop.
